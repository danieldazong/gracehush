# Screen specifications

> Part of the GraceHush rules, moved out of `AGENTS.md` word for word on 2026-11-23. `AGENTS.md` is the short core that every session loads, and its "Rules index" says which file holds which section. The sections below keep their original `##` headings, so a reference such as "AGENTS.md, Crisis Safety Rules" finds them. A rule that changes is changed here, in its section, in a few lines; a step's history goes to `docs/build-log.md`. This file can be long: search it (`git grep -n "<words>" docs/rules/screens.md`) and read only the part you need.
